# Reproducing two-host SGLang NIXL staging

Compare two SGLang revisions on the same hardware with Qwen3-0.6B BF16. One prefill rank and the client run on machine A. Two decode ranks run on B. This companion includes the result hooks, deterministic prompts, launcher and offline validator. The [measured results](EVIDENCE.md) include both host pairs and the run with no instrumentation in the transfer worker. It contains no model weights or run logs.

## Requirements

Use two Linux hosts with one available GB200 on A and two on B, a GPU RDMA path, reachable service and collective ports, a shared writable output directory and a private tmpfs at `/dev/shm`. Run both hosts with the same SGLang Python dependencies. The reference software used Python 3.12, PyTorch 2.14.1+cu130, sglang-kernel 0.4.11, NIXL 1.5.2 and UCX 1.23.0. The UCX protocol-table check expects the zero-copy RC/DC GPU PUT log format of that version. Run on a trusted benchmark network; servers bind both service addresses. Service/bootstrap ports include 19101, 19102, 19601, 19602, 19898 and 19899; transports may open additional ports.

Both machines need a git checkout with the [baseline revision](https://github.com/sgl-project/sglang/tree/0730305dbee380a841640c50510ebe3e9e1d9302) and the candidate source under test. Set `PATCH_REF` to the actual PR head or a ref you fetched locally. The validator expects the exact tested transport sources and will reject a different implementation. The pinned model and tokenizer are public. Download into a local directory, preserving the metadata generated by `hf download`. [Qwen3-0.6B revision](https://huggingface.co/Qwen/Qwen3-0.6B/tree/c1899de289a04d12100db370d81485cdf75e47ca)

## Run

Run this setup on each host, with your own paths and the same fresh shared output location. Set A and B to resolvable service addresses visible to both machines. The local GPU ordinals default to 0 on A and 0,1 on B. Set `PREFILL_GPU_IDS` or `DECODE_GPU_IDS` to select other ordinals. Start Python in a GPU environment with the ordinals selected for this process visible through the container runtime.

```bash
export SGLANG_REPO=/path/to/sglang PATCH_REF=your-fetched-pr-ref
export MODEL=/path/to/models/Qwen3-0.6B
export A=prefill.example B=decode.example OUT=/shared/pd-experiment/run1
hf download Qwen/Qwen3-0.6B --revision c1899de289a04d12100db370d81485cdf75e47ca --local-dir "$MODEL"
cd /path/to/this/companion
```

Create the plan once, then start one command on each machine concurrently. Keep both in the foreground. The launcher materializes temporary git snapshots and instruments those copies.

```bash
# Once on A
mkdir "$OUT"
python plan.py freeze . "$OUT"

# On A
bash run_host.sh 0 "$A" "$B" "$OUT"

# In a separate terminal on B
bash run_host.sh 1 "$A" "$B" "$OUT"
```

After both exit, validate on either host. Exit code 0 means every cell qualified; 1 also accompanies a token mismatch in any cell. The JSON keeps qualified cells' comparisons and withholds burst statistics for any cell that failed the controls. Inspect the terminal for structural errors. Reusing an output directory from an earlier launch is rejected.

```bash
python validate.py "$OUT"
python - "$OUT/buffered-endpoint-results.json" <<'PY'
import json, sys
with open(sys.argv[1]) as f:
    data = json.load(f)
for c, v in data["bursts"]["cases"].items():
    for order in v.get("orders", []):
        m = order["metrics"]["first_prefill_to_last_decode"]
        print(c, order["execution_order"], "patch − base, µs", m["paired_median_delta_us"])
PY
```

## What is measured

Each arm serves the same deterministic English prompts of 64 or 2,048 tokens at closed-loop concurrency 1 and 4, with 2 warmup waves and 24 measured waves per cell. The random seed is the room ID. Digests cover the exact input IDs. All requests generate two greedy tokens. Two independent direct P1→D2 runs supply references. A monolithic TP2 run supplies a secondary diagnostic. Every routed run also replays the same requests serially with token scores. Timed arms run baseline, candidate, candidate, baseline.

The first endpoint is when the prefill scheduler processes token one. The second is the later of the two decode ranks' first result callbacks for token two on the same request. Each wave spans its earliest prefill endpoint to its latest such decode endpoint. Client latency spans first departure to last full HTTP return on A. Twenty four-timestamp TCP exchanges before and after each wave bound conversion from B's monotonic clock to A's, assuming relative drift ≤1,000 ppm and a maximum accepted interval width of 200 µs. The paired-median range propagates clock uncertainty. A separate order-statistic interval treats the 24 paired waves within an order as independent.

`install_endpoints.py` instruments only the scheduler result callbacks. `endpoint_trace.py` writes fixed binary records in tmpfs. The validator checks both ranks' first token, input hashes, outputs from both direct controls, recorded batch membership, and the sender's UCX protocol tables for each expected chunk size. Protocol tables describe the selected route; the benchmark measures service endpoints. Closed-loop HTTP requests/s excludes time between waves.

## Portable changes

The workload, role logic, source hooks, clocks, route checks and burst statistics come from the measured harness. This launcher switches to local git snapshots, configured GPU ordinals, a shared output directory and address binding in place of resource-manager placement. Model, transport source and result checks remain. The offline validator accepts any two distinct participating hosts. The model and tested SGLang source file hashes identify public artifacts. Raw runtime logs may contain local device or host identifiers.

Run the CPU regression tests with `python -m unittest discover -v`. The GPU pair must still be run in a suitably configured environment.
